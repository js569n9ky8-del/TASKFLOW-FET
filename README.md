
# TaskFlow FET

## Descripción
TaskFlow FET es una aplicación web desarrollada para gestionar tareas académicas mediante operaciones CRUD.

Permite registrar, consultar, editar y eliminar actividades, además de buscar y filtrar tareas por estado.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- LocalStorage
- Visual Studio Code
- ChatGPT como asistente de desarrollo mediante IA

## Funcionalidades
1. Crear tareas.
2. Consultar tareas.
3. Actualizar tareas.
4. Eliminar tareas.
5. Buscar actividades.
6. Filtrar por estado.
7. Guardar información en LocalStorage.

## Instalación y ejecución

1. Descargar o clonar este repositorio.
2. Abrir la carpeta TASKFLOW_FET.
3. Abrir el archivo index.html en el navegador.
4. También se puede ejecutar con Live Server desde Visual Studio Code.

No requiere servidor ni instalación de dependencias.

## Almacenamiento
Los registros se almacenan en LocalStorage del navegador.
Los datos permanecen disponibles al recargar la página en el mismo navegador.

## Prompts utilizados en el desarrollo con IA

### Prompt 1: Planificación
"Actúa como desarrollador web y propón una aplicación CRUD sencilla para gestionar tareas académicas."

Objetivo: definir el proyecto y sus funcionalidades.

### Prompt 2: Diseño
"Crea una interfaz web moderna y adaptable utilizando HTML y CSS para una aplicación de tareas académicas."

Objetivo: construir la apariencia de la aplicación.

### Prompt 3: Funcionalidad CRUD
"Implementa crear, consultar, actualizar y eliminar tareas con JavaScript y LocalStorage."

Objetivo: desarrollar las operaciones principales.

### Prompt 4: Validaciones
"Agrega validaciones para los campos obligatorios y confirmación antes de eliminar registros."

Objetivo: mejorar la seguridad y experiencia de uso.

### Prompt 5: Mejoras
"Agrega un buscador, filtros por estado y contadores de tareas pendientes, en proceso y completadas."

Objetivo: mejorar la administración de actividades.

### Prompt 6: Revisión
"Revisa el código JavaScript, identifica errores y mejora la organización de las funciones sin cambiar las funcionalidades."

Objetivo: revisar y refactorizar el código.

La inteligencia artificial se utilizó como herramienta de apoyo para planificar, generar, revisar y mejorar el código. La autora debe verificar el funcionamiento, comprender las instrucciones y validar personalmente el resultado final.
